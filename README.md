# 文墨天机 · 紫微斗数排盘

纯前端的紫微斗数排盘工具，无后端依赖，命盘数据保存在浏览器 localStorage。

## 快速开始

需要 Node.js 18 或更高版本。

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器
npm run build   # 构建到 dist/
npm run preview # 本地预览构建产物
```

## 功能

**排盘**
- 公历 / 农历输入，农历支持闰月
- 真太阳时校正（可填出生地经度，默认东经 120°）
- 快捷输入：一串数字直接填日期，支持 8 / 10 / 12 位（`201806180408` = 2018-06-18 04:08）

**七级盘**
本命盘 → 大限盘 → 流年盘 → 流月盘 → 流日盘 → 流时盘，另有小限盘。顶部工具条可一步直达任意盘级。

**盘面**
- 传统 4×4 盘面 / 宫位卡片列表两种布局，右上角切换
- 点选宫位查看三方四正、宫干四化飞星、限盘四化、立太极换算
- 宫位支持键盘操作（Tab 聚焦、Enter / Space 选中）

**给 AI 的文本导出**
- 完整模式：12×12 全量打印，每组自包含
- 精简模式：省略组内重复的宫位固有内容，改为按宫序编号回查总览，体积减少约 68%
- 选中大限后可下载该大限**十年流年**的 TXT，逐年内容与在页面上点选该年完全一致

详略可在「安星 / 显示设置 › AI 文本」切换。

**命盘库**
保存 / 读取 / 重命名 / 删除，支持导出 JSON。上限 200 条。

**河洛理数**
与紫微斗数共用同一套出生资料，在工具条「术数」处切换。

- 天地数起卦：先天卦 → 后天卦，含元堂爻位、纳甲六亲世应、互卦覆卦
- 起卦详情：纪年（黄帝纪元）、数理、数名、气运、值月消息卦、元气化工、先后天八卦变化、五命、命格、十吉、卦气旺衰、命局对体
- 四级下钻：大限（阳爻 9 年 / 阴爻 6 年）→ 流年 → 流月 → 流日，逐层点开看爻辞与理数
- 卦象六爻图与爻辞：易经爻辞、摘要、诗歌、易经爻辞推命
- 9 项流派开关（取数法、五寄中宫、三至尊卦、纯乾坤落爻、流年次步、流月起月、流月列流日、纪年基准、取化工法）
- 盘面文本可一键复制

## 目录结构

```
src/
  App.vue              主界面、表单校验、状态编排
  components/
    ZiweiPan.vue       盘面容器（网格 / 列表两种布局）
    GongCell.vue       单个宫位
    XianBar.vue        限流盘速查条
    SettingsPanel.vue  安星与显示设置
    ChartLibrary.vue   命盘库
    HeLuoPan.vue       河洛理数盘面
  heluo/                 河洛理数（移植自 horosa-web-app）
    heluoLocal.js      算法内核（纯函数，只依赖条文 JSON）
    heluo.js           适配层：把排盘结果 / 节气喂给内核
    ganzhiYearBase.js  干支年基准（立春界纠偏）
    gua64.js           六十四卦纳甲六亲世应
    data/
      heluoTiaowen.json  六十四卦条文（卦辞 / 爻辞 / 推命）
  ziwei/
    paipan.js          排盘核心
    xianpan.js         限流盘（大限 / 流年 / 流月 / 流日 / 流时 / 小限）
    lunar.js           公历农历互转
    config.js          安星参数与开关元数据
    data.js            星曜、宫位、四化基础数据
    taiji.js           立太极换算
    export.js          导出给 AI 的 Markdown 文本
    store.js           localStorage 读写
tools/                 源码分析与校验脚本
tests/                 自校验脚本
```

## 说明

- 全部计算在浏览器端完成，不上传任何数据。
- 命盘库存于 localStorage，清理浏览器数据会丢失，建议定期导出 JSON 备份。
- 排盘结果仅供传统文化研究参考。
